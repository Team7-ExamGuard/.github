## 📌 프로젝트 소개

**ExamGuard**는 온라인 시험 플랫폼을 프론트엔드부터 백엔드까지 직접 개발하고, 이를 **시험 중 어떤 장애가 발생해도 답안이 유실되지 않도록 운영하는 것**을 목표로 하는 클라우드 인프라 프로젝트입니다.

온라인 시험은 수많은 응시자가 같은 시간에 접속하고, 시험이 끝날 때까지 답안 저장 요청이 끊임없이 발생합니다. 이때 서버 하나만 멈춰도 응시자가 작성한 답안이 사라질 수 있고, 시험은 다시 치를 수 없습니다. 그래서 이 프로젝트의 기준은 단순히 "서비스가 떠 있는가"가 아니라 **"장애가 나도 답안이 저장되는가, 그리고 장애 이후 최신 답안이 정확히 복원되는가"** 입니다.

이를 위해 물리 장비 3대 위에 **온프레미스 Kubernetes HA 클러스터를 직접 구축**하고, 애플리케이션 · 데이터베이스 · 클러스터 제어 영역 각각에 고가용성을 적용합니다. 이후 **AWS EKS와 연결하는 하이브리드 멀티 클러스터**로 확장하여 사용자 접점과 요청 처리 계층을 분산하고, 핵심 로직과 답안 원본 데이터는 온프레미스에서 관리합니다.

k6로 시험 시작 시각의 접속 폭주를 재현해 **부하에 따라 Pod가 자동으로 확장되는지** 확인하고, 부하가 걸린 상태에서 **물리 장비 1대의 전원을 실제로 차단해도 답안 저장이 끊기지 않는지** 검증합니다. 이와 함께 Pod 장애, DB Primary 장애조치, 네트워크 단절 상황을 재현하여 답안 저장 성공률 · 복구 시간 · 데이터 정합성을 실제 측정값으로 비교합니다.
