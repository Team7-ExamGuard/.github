
# LaneShift 🚗

### 온프레미스·퍼블릭 클라우드를 묶어 가입자가 늘어난 마켓을 셀 단위로 무손실 이전하는 커넥티드카 하이브리드 플랫폼

**현대오토에버 모빌리티 SW 스쿨 4기 | Cloud Track 최종 프로젝트**

- **프로젝트 기간:** 2026.10 ~ 2026.12
- **프로젝트 형태:** 개인 프로젝트 (1인 기획·설계·구축)
- **프로젝트 분야:** Cloud Infrastructure / DevOps

---

## 📌 프로젝트 소개

**LaneShift**는 현대자동차그룹의 커넥티드카 서비스(CCS)를 위한 퍼블릭 클라우드와 자체 프라이빗 클라우드인 **hCloud의 병행·확장 운영 방식을 참고하여, 이를 작게 재현하는 개인 프로젝트**입니다.

현대자동차그룹은 가입자 수가 적은 지역에서는 퍼블릭 클라우드를 활용하고, 특정 지역의 가입자 수가 증가하면 프라이빗 클라우드로 전환하여 hCloud를 확장 제공하는 방식으로 운영하고 있습니다.

> 관련 기사: [현대자동차가 구축한 ‘H클라우드’, 전세계 1000만 커넥티드 카 서비스 뒷받침 — 바이라인네트워크 (2024.06)](https://byline.network/2024/06/24-313/)

이러한 운영 모델을 바탕으로 **AWS 기반 퍼블릭 클라우드와 OpenStack 기반 프라이빗 클라우드를 연계**하여, 가입자 규모에 따른 클라우드 운영 환경 전환을 소규모로 재현합니다.

특히 **'언제 이전할 것인가'와 '어떻게 데이터 손실 없이 이전할 것인가'** 에 초점을 맞춰, 마켓별 셀(Cell) 단위 무손실 이전 프로세스와 장애 대응 체계를 자체적으로 설계·구현하는 것을 목표로 합니다.

## 🎯 핵심 구현 목표

- **Hybrid Cloud:** AWS와 OpenStack 기반 하이브리드 클라우드 인프라 구축
- **Cell-Based Architecture:** 마켓별 독립적인 서비스 운영을 위한 셀 기반 아키텍처 설계
- **Migration:** 가입자 수·부하·비용 등을 고려한 이전 의사결정 및 셀 단위 무손실 이전 구현
- **High Availability:** 퍼블릭·프라이빗 클라우드 장애에 대비한 서비스 연속성 및 복구 전략 수립
- **Observability:** 퍼블릭·프라이빗 클라우드 통합 모니터링 환경 구축

## 🔄 주요 운영 시나리오

1. **초기 운영:** 가입자 규모가 작은 마켓은 AWS 퍼블릭 클라우드에서 운영
2. **마켓 성장:** 가입자 수와 서비스 부하 증가에 따른 프라이빗 클라우드 전환 필요성 판단
3. **클라우드 이전:** 대상 마켓의 셀을 OpenStack 프라이빗 클라우드로 데이터 손실 없이 이전
4. **서비스 전환:** 데이터 정합성과 서비스 상태를 검증하고 트래픽 전환
5. **장애 대응:** 클라우드 장애 발생 시 서비스 복구 및 연속성 확보
6. **통합 관측:** 하이브리드 클라우드 전반의 인프라 및 서비스 상태 모니터링
