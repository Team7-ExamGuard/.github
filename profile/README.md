## 📌 프로젝트 소개

ExamGuard는 대형 학원의 중등부 정기 테스트처럼 수백 명의 학생이 같은 시각에 응시하는 온라인 시험 플랫폼을 프론트엔드부터 백엔드까지 직접 개발하고, 시험 중 어떤 장애가 발생해도 답안이 유실되지 않도록 운영하는 것을 목표로 하는 클라우드 인프라 프로젝트입니다.

학원 정기 테스트는 정해진 시각에 학생 수백 명이 한꺼번에 접속하고, 시험이 끝날 때까지 답안 저장 요청이 끊임없이 발생합니다. 이때 서버 하나만 멈춰도 학생이 작성한 답안이 사라질 수 있고, 같은 조건으로 시험을 다시 치르기도 어렵습니다. 테스트 결과는 반 편성과 학부모 상담으로 이어지기 때문에, 답안 유실은 곧 학원의 신뢰 문제가 됩니다. 그래서 이 프로젝트의 기준은 단순히 "서비스가 떠 있는가"가 아니라 "장애가 나도 답안이 저장되는가, 그리고 장애 이후 최신 답안이 정확히 복원되는가" 입니다.

이를 위해 학원이 자체 운영하는 물리 장비 3대 위에 온프레미스 Kubernetes HA 클러스터를 직접 구축하고, 애플리케이션 · 데이터베이스 · 클러스터 제어 영역 각각에 고가용성을 적용합니다. 서비스는 ArgoCD 기반 GitOps로 배포하여 Git에 정의된 상태를 클러스터에 그대로 유지하고, 잘못된 배포는 롤백으로, 수동 변경은 self-heal로 되돌립니다. 또한 LGTM 스택(Loki · Grafana · Tempo · Mimir)으로 메트릭 · 로그 · 트레이스를 한 곳에서 관측하여, 장애가 났을 때 알림 → 대시보드 → 로그 · 트레이스 순서로 원인을 추적할 수 있게 합니다.

k6로 시험 시작 시각에 학생 300명이 한꺼번에 접속하는 상황을 재현해 부하에 따라 Pod가 자동으로 확장되는지 확인하고, 부하가 걸린 상태에서 물리 장비 1대의 전원을 실제로 차단해 Control Plane과 Worker가 동시에 사라져도 답안 저장이 끊기지 않는지 검증합니다. 이와 함께 Pod 장애, DB Primary 장애조치, 잘못된 버전 배포 후 롤백 상황을 재현하여 답안 저장 성공률 · 복구 시간 · 데이터 정합성을 실제 측정값으로 비교합니다.
